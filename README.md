**Fall seven times. Stand up eight.**

<br>

I believe good engineering isn't just about writing more code.

It's about:

* understanding the problem
* choosing the right abstraction
* learning from failure
* keeping things maintainable
* and making the final experience feel intentional

### My rules

**01 — Learn deeply.**
Documentation first. Guessing later.

**02 — Build often.**
Ideas become useful only when they become real.

**03 — Break things.**

**04 — Fix beautifully.**

**05 — Keep evolving.**
The next version should always be better.
